как запустить проект : npm run dev
какие сценарии покрыты тестами: 
    рендер селектов и полей с мок-данными
    пересчет конвертации при изменении суммы/пары
    запрет на одинаковые валюты в паре
    reset дочернего состояния по key
где лежат мок-данные, как они подключены и как устроена их структура:
    данные лежат в src/mocks
    в src/models лежат типы
    мок-данные импортируются в app.tsx и подключаются к константам:
        currencies: Currency[] - массив валют;
        priceChanges: Record<string, Record<string, PriceChange>> - вложенный объект
где и зачем использован reset по key:
    он использован в components/app/app.tsx 
    key={`${from}${to}`} //key нужен здесь для пересоздания moreabout при смене валют в селекте. В селекте поменяли валюту - key изменился, соответственно moreabout создасться заново и isVisible снова false.
